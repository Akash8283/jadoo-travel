# 🌐 Responsive Website Project

A fully responsive website built using **HTML, CSS, and Bootstrap**, designed to provide a clean, modern, and user-friendly interface across all devices.

## ✨ Features
- 📱 **Responsive Design** – Works seamlessly on mobile, tablet, and desktop  
- 🎨 **Modern UI** – Clean and attractive design with Bootstrap components  
- ⚡ **Fast & Lightweight** – Optimized structure for smooth performance  
- 🧩 **Reusable Components** – Built with maintainable and scalable code  

## 🛠️ Technologies Used
- **HTML5** – Semantic and structured markup  
- **CSS3** – Styling with Flexbox & Grid  
- **Bootstrap 5** – Pre-built responsive components
